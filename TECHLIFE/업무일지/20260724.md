5. VPN 구간 작업 절차
   - Transit VPC Connect를 생성하여 서버 VPC와 Transit VPC를 연결한다.
   - 서버 VPC의 Route Table에 목적지 CIDR에 대한 Target을 Transit VPC Connect로 설정한다.
   - Service Function Chain(SFC)에 목적지 CIDR에 대한 Chain(IPS > FW > VGW)을 등록한다.
   - Transit VPC Connect 유형의 Endpoint Route Table에 목적지 CIDR에 대한 Target을 해당 SFC로 설정한다.
   - 이때 Chain에 등록된 IPS, FW의 Route Table 에도 목적지 CIDR 이 추가되어야 한다.

6. Server 에서 VPN 목적지까지의 라우팅 흐름
   → VPC Route Table ( 10.231.0.0/16 → Transit VPC Connect )
   → Transit VPC
   → Endpoint RT(10.231.0.0/16 → SFC)
   → SFC(IPS → FW → VGW)
   → VPN Tunnel
   → On-Prem
